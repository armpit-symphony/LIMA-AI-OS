# V1 Post-G60 Next Lane Decision Matrix

Date: 2026-06-20
Branch: `docs-v1-post-g60-readiness-and-next-lane-matrix`
API status: `CANDIDATE_ONLY`

This matrix compares the next candidate lanes after V1-G60. G60 added the approved `openai>=1.0.0,<3.0.0` dependency declaration to `pyproject.toml` and recorded vendor provider SDK import-boundary evidence. It did not edit a lockfile, add runtime vendor SDK imports in `lima/`, prove installed runtime import execution, build SDK clients, construct provider clients, access credentials, resolve provider endpoints, perform provider egress, execute fallback, wire consumers, or claim product readiness.

## Recommendation

Recommended next direction: prepare the next exact operator request for a narrow runtime vendor SDK import execution proof lane, still request-only and with no implementation in this branch.

This should come before any built-in provider SDK client implementation, provider client construction, credential value access, LIMA-owned endpoint resolution, LIMA-owned provider network egress, fallback execution, connector/browser/network authority, consumer production runtime integration, physical-world authority, product-readiness lane, or final API freeze. The next request must keep dependency declaration, dependency installation, lockfile edit, runtime vendor SDK import execution, SDK client construction, credential access, endpoint authority, network egress, and runtime invocation as separate gates.
